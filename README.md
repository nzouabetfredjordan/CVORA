# CVORA

Application web React/Vite pour créer, personnaliser et télécharger des CV professionnels.

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Déploiement Vercel

Importez le dossier sur Vercel. La configuration `vercel.json` utilise automatiquement le dossier `dist` et gère les routes SPA.
